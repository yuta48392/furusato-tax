# ふるさと納税シミュレーター

2025 年度（令和 7 年）向けのふるさと納税控除上限額と税額内訳を算出するサーバーレス対応 Web アプリです。Next.js(App Router) と独立した計算エンジン (`packages/tax-engine`) で構成しており、クライアント計算と API 計算を切り替えられます。

## 開発環境

```bash
npm install
npm run dev       # apps/web を起動
npm run test      # vitest でユニット / API テスト
```

## ディレクトリ構成

- `apps/web` - Next.js (App Router) フロントエンドと API Route
- `packages/tax-engine` - 税計算ロジック（純粋関数）
- `packages/rules` - 年度別パラメータ
- `tests` - vitest によるユニットテスト

## 仕様メモ

- 給与所得控除は 2025 年度ルール（支払金額÷4 を千円未満切捨て、3.2 倍して 44 万円控除）を実装
- 所得税速算表、住民税 10% + 均等割 5,000 円、簡易的な調整控除モデルを実装
- ふるさと納税は所得税 5.105%、住民税 10%、残余を特例分として扱い、住民税所得割 20% を上限に試算

本計算はあくまで目安です。実際の税額や申告は自治体・税務署の案内を優先してください。
